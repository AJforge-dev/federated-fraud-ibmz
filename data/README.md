# Data Directory

Download the official **Kaggle Credit Card Fraud Detection** dataset:
- Link: [mlg-ulb/creditcardfraud](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
- Expected file: `creditcard.csv` (284,807 transactions, 30 features, Class)

Place `creditcard.csv` in this directory (`data/creditcard.csv`).

*Note: If `creditcard.csv` is absent, the project will automatically generate realistic synthetic fallback data so all benchmarks remain 100% runnable.*
